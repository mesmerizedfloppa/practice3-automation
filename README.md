**Вариант:** 7 (нотариальная контора)  
**Дисциплина:** ИТ-инфраструктуры, КазНИТУ имени К.И. Сатпаева

## Параметры варианта

- Отделы и файлы (задание 1): `clients`, `contracts` — по 10 файлов в каждом отделе.
- Хранить копий (`KEEP_LAST`): 8.
- Организация (задание 5): нотариальная контора, 80 ГБ, 80 МБ/с, копия раз в неделю, RPO 24 ч, RTO 4 ч.

## Файлы

| Файл | Назначение |
|---|---|
| `make_test_data.py` | создаёт папку `company_data/` с тестовыми CSV-файлами отделов `clients` и `contracts` |
| `backup.py` | создаёт архив `backups/backup_<дата>_<время>.tar.gz` и рядом JSON-манифест с SHA-256 архива и каждого файла; удаляет копии сверх `KEEP_LAST` (ротация); проверяет восстановление и выводит отчёт о различиях (отсутствуют / лишние / изменены); восстанавливает данные из архива и замеряет время |
| `rpo_rto.md` | расчёт RPO и RTO для задания 5 |
| `.gitignore` | исключает `company_data/`, `backups/`, `restore_test/` из репозитория |

## Запуск (Python 3.12+, только стандартные модули)

```
python make_test_data.py      # 1. создать тестовые данные
python backup.py              # 2. создать копию + ротация + проверка восстановления
python backup.py verify       # 3. проверить восстановление последней копии
python backup.py restore      # 4. восстановить company_data из последней копии
```
